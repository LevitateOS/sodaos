# Spaces repository and terminal icons

Unmodified `repo-16.svg`, `terminal-16.svg` and `LICENSE` from the official
`@primer/octicons` 19.14.0 npm archive, the icon package selected by Forgejo 15.0.7.
The filenames include the source version; no new workspace dependency is installed.

Source: https://registry.npmjs.org/@primer/octicons/-/octicons-19.14.0.tgz

The archive was verified against the npm release's SHA-512 integrity value before
extracting these three regular files. Forgejo's generated SVGs use the same icons
with its own optimization. Soda uses CSS masks so the unchanged artwork inherits
canonical theme colors. The payload map stages both icons, this provenance and the
MIT license together. GitHub's copyright does not imply GitHub repository support
