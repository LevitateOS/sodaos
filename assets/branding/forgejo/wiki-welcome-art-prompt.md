## Exact prompt

Create a Soda papercraft illustration for an empty repository wiki welcome page. Reference image 1 is primary for robot identity, cardstock material and warm light; image 2 for compactness; image 3 for proportions. Same short cream matte cardstock robot, rounded rectangular head, navy inset face, cyan oval eyes and small smile, cobalt circular earcaps, navy mittens/joints/soles, no antenna. Robot opens a large cream blank reference book with cobalt cover and a single mint ribbon bookmark, inviting the first page to be written. Book angled toward viewer, robot behind and left holding one page gently; no lettering, scribbles, symbols or completed content. One clear action readable at 180px. Thin cobalt felt mat. Fine paper grain/seams, no glossy plastic. Slightly elevated three-quarter studio composition, warm soft lighting, cream/navy/cobalt/mint palette. Center entire scene with generous margins, 1536x1024 landscape PNG, actual transparent alpha outside robot/book/mat, no backdrop or checkerboard. No plants, drinks, laptop, extra books, logos, watermarks or extra robots.

Remove the background from this image. Make the background transparent. Keep the robot, all objects, and blue mat exactly as they are. Output an RGBA PNG with an alpha channel.
