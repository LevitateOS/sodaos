# Factory product implementation plan

The canonical [plan and full completion standard](https://github.com/LevitateOS/factory/blob/main/docs/development/factory-products/ideal-filetree-plan.md) now live in [LevitateOS/factory](https://github.com/LevitateOS/factory), with the current [implementation queue](implementation-tasks.md).

Local owner: [/home/vince/Projects/factory/docs/development/factory-products/ideal-filetree-plan.md](/home/vince/Projects/factory/docs/development/factory-products/ideal-filetree-plan.md).

The scope remains an installed Linux Factory desktop with connected issue/PR views, policy-admitted automation, native execution/publication/review/correction, retained-data upgrade, and shared component changes in both desktop and Fountain. macOS follows Linux. A source build, workbench or completed slice does not satisfy that outcome.

Forge owns appliance composition and native Fountain adapters. Factory owns the shared engine, application services, canonical store/domain packages and product UI. The Go consumer cutover is implemented locally; shared UI consumption is also implemented and locally qualified. The native Rust consumer cutover is also implemented locally; installed qualification remains pending. Original source and planning evidence are preserved in the Factory import commits and recovery snapshots.
